macOS-Aqua-themed sibling of wasmbox. Wayland-inspired single-instance compositor written in pure Ruby, running in WebAssembly. Three traffic-light buttons on the LEFT (à la macOS). Same external-client protocol as wasmbox, so the same hello / dock / quake / terminal / files wasm clients work unmodified.
